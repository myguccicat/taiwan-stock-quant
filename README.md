## 🔬 實驗紀錄與關鍵發現

### 發現一：效率市場假說驗證
RF 分類模型（預測漲跌方向）AUC 僅約 0.45，低於隨機猜測基準（0.5），
驗證了台股在日線級別的弱式效率市場特性。

### 發現二：排序優於分類
改用回歸模型預測相對強弱排名（Spearman IC +0.0285），
比直接預測漲跌方向更有實際交易價值。

### 發現三：風控在多頭市場反效果
| 風控版本 | 超額報酬 | 結論 |
|---------|---------|------|
| 無風控（最終採用）| +38.7% | ✓ 最佳 |
| 大盤MA20空手過濾 | -14.9% | V型反彈踏空 |
| 平滑倉位風控 | -58.9% | 成本過高 |

### 發現四：籌碼面特徵無顯著效益
加入三大法人買賣超資料後，模型績效幾乎無改變
（+386.1% vs +384.2%），技術面特徵已包含足夠資訊。

### 發現五：縮短預測窗口可提升排序訊號強度
比較 5 日與 3 日預測窗口（其他特徵與模型架構完全相同）：

| 指標 | 5日週期版本 | 3日週期版本 |
|---|---|---|
| Spearman Rank IC（平均） | +0.0182 | **+0.0649** |
| 多空組合累積報酬 | -0.2% | +1116.3% |
| 最重要特徵 | near_high（28.8%）| r1（20.2%）|
| 第二重要特徵 | r5（11.9%）| ma5_ratio（16.1%）|

> ⚠️ 以上累積報酬**未扣除交易成本與滑價**，僅反映模型排序能力（Rank IC），
> 不代表可實現的真實交易報酬。實際含成本回測請見上方「核心回測結果」。

縮短預測窗口使 IC 提升超過 3 倍，且模型依賴的主導特徵由中期突破型態
（near_high）轉為短期價格慣性（r1、ma5_ratio），顯示台股短期動能效應
在更短時間窗口下更明顯。此為同一模型架構在不同預測目標超參數下的
敏感度測試，非獨立策略比較。

### 發現六（待確認）：3日換倉+持倉緩衝機制的回測結果存在多變數混雜問題

**測試日期**：2026-06-18
**狀態**：⚠️ 待拆解驗證，數字暫不採用為核心結果

在嘗試把「3日預測窗口」整合進含交易成本的實際回測（`day19_ml_backtest.py`）時，
同時改動了三個變數，導致無法單獨歸因報酬提升的真正原因：

1. 換倉週期由 5 日改為 3 日（換倉次數 39 → 66 次）
2. 年化報酬計算公式由「日報酬均值複利外推」改為「首尾日期差精確年化」
3. 新增持倉緩衝機制：舊持股只要排名仍在前 10 名就續抱，不強制換成當日預測最強的前 5 名

### 數字對照（未拆解版本）

| 指標 | 舊版（5日，無緩衝）| 新版（3日+緩衝+新年化公式）|
|---|---|---|
| ML策略年化報酬 | +297.8% | +388.6% |
| 等權基準年化報酬 | +259.1% | +183.5% |
| 超額年化報酬 | +38.7% | +205.1% |
| Sharpe Ratio | 2.54 | 3.05 |
| 最大回撤 | -22.7% | -17.3% |
| 總交易成本 | 12.66% | 16.99% |

### 為何標記為「待確認」

等權基準（持有全部47檔，理論上不受換倉邏輯或緩衝機制影響）的年化報酬
從 +259.1% 大幅變動為 +183.5%，差距達 76 個百分點。由於基準計算本身
不涉及模型排序或持倉緩衝，這個落差**幾乎可以全部歸因於年化公式的改變**，
代表兩種年化計算方式本身存在顯著差異，尚未確認哪一種（或兩者皆）更符合
業界標準的年化報酬計算慣例。

此外，「持倉緩衝機制」本身會降低換手率、傾向延長持有已上漲的股票，
這可能讓回測報酬部分來自「減少不必要換手」的效果，而非單純的模型排序
能力提升，與發現五（純訊號強度測試，IC提升）的結論不應混為一談。

### 下一步驗證計畫

- [ ] 固定年化公式不變，僅切換換倉週期（5日 vs 3日），單獨確認週期影響
- [ ] 固定換倉週期不變，僅切換年化公式，確認基準數字差異是否消失
- [ ] 移除持倉緩衝機制，測試純3日換倉（無緩衝）的含成本報酬，
      與發現五的訊號強度結論做正確比對
